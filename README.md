# Yadro — ядро управления реабилитационной беговой дорожкой

Кроссплатформенное C++ ядро управления дорожкой с web-интерфейсом, доступным по IP.

Проект ориентирован на Windows/MSYS2 и Linux. Web-страницы и ресурсы хранятся в `data/static/`, backend предоставляет REST API для управления дорожкой, телеметрии, профилей и тестовых протоколов.

> Важно: управление реальным силовым оборудованием должно подключаться через отдельный аппаратный драйвер. До подтверждения протокола контроллера используется безопасный `SimulationDriver`.
