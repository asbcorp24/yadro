# Матрица экранов REATERRA → YADRO Web

Эта матрица используется как критерий полноты переноса интерфейса: каждый экран/состояние старого пульта имеет отдельную HTML-страницу либо явно обозначенный рабочий экран выполнения. Все рабочие действия идут через C++ REST API; декоративные заглушки не считаются реализацией.

## Процедуры и тестирование

| Экран старого пульта / состояние | Web-экран | Реализация |
|---|---|---|
| Выбор типа процедуры | `index.html` | Переходы: тестирование, свободный бег, профиль, ЧСС, пациенты, настройки |
| Выбор метода тестирования | `testing.html` | Стандартный / пользовательский / внешняя стресс-система |
| Список стандартных протоколов | `protocols.html` | `/api/v1/protocols` |
| Карточка/ступени стандартного протокола | `protocol-detail.html` | Таблица ступеней, длительность, скорость, уклон, доступность |
| Выполнение тестового протокола | `test-run.html` | `/api/v1/control/start`, `/stop`, `/state`, E-stop |
| Список пользовательских протоколов | `user-protocols.html` | `/api/v1/user-protocols` |
| Редактор пользовательского протокола | `user-protocol-editor.html` | CRUD `/api/v1/user-protocols` |
| Внешняя стресс-система | `external.html` | REST-контур управления и телеметрии |

## Offline Bootstrap

- Bootstrap 5.3.3 фиксированной версии скачивается CMake в `data/static/vendor/bootstrap/`.
- `style.css` импортирует только локальный `vendor/bootstrap/bootstrap.min.css`.
- `app.js` загружает только локальный `vendor/bootstrap/bootstrap.bundle.min.js`.
- После конфигурации/установки web-пульт не использует CDN и не требует Интернет для работы.
- `scripts/check_static_ui.py` проверяет наличие всех экранов, локальных ссылок и Bootstrap assets в CI.

## Ограничения аппаратной части

- Сейчас используется `SimulationDriver`; управление реальным приводом REATERRA не заявляется до определения аппаратного протокола.
- Browser E-stop не заменяет физическую аварийную цепь и концевики безопасности.
- Мощность/энергия в симуляции являются расчётными оценками.
